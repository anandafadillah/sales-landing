# Label triage

Skill-skill ini memakai lima peran triage baku. File ini memetakan peran tersebut ke nama label yang benar-benar dipakai di issue tracker repo ini.

| Label di mattpocock/skills | Label di tracker kita | Arti                                          |
| -------------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`        | Perlu dievaluasi dulu oleh maintainer         |
| `needs-info`               | `needs-info`          | Menunggu info tambahan dari pelapor           |
| `ready-for-agent`          | `ready-for-agent`     | Sudah jelas lengkap, siap dikerjakan agent    |
| `ready-for-human`          | `ready-for-human`     | Harus dikerjakan manusia                      |
| `wontfix`                  | `wontfix`             | Tidak akan dikerjakan                         |

Kalau skill menyebut sebuah peran (misal "pasang label siap untuk agent"), pakai nama label dari kolom kanan tabel ini.

Ubah kolom kanan kalau nanti kamu pakai nama label yang berbeda.
